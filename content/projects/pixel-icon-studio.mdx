Pixel Icon Studio is a small utility I made with Glaze, Raycast's agentic app builder, to design the pixel icons used across this site.

The app started as a simple 11-by-11 grid editor and grew into a more complete local tool: a dashboard for saved icons, a canvas for drawing and editing pixels, folders and tags for organization, import/export flows, and code views for moving the finished icons back into a React icon system.

## Library

The opening view is a dense library of saved icons. Cards keep the artwork large enough to scan quickly, while the sidebar handles folder navigation and preferences without sending the user into a separate settings window.

## Editor

The editor is built around a crisp square canvas with a small floating tool bar for move, paint, erase, brush size, color, and clearing the canvas. The surrounding panels carry the heavier information: layers on the left, inspector details on the right.

  <ImageModal src={editorInfo} caption="Canvas metadata, tags, file details, and grid size controls" />
  <ImageModal src={editorPreview} caption="Actual-size preview at 1x, 2x, and 3x" />

The canvas supports drawing and editing behaviors that feel closer to a design tool than a form: drag to paint, command-drag to erase, shift to constrain strokes, lasso selection from the margin, arrow-key nudging, grouping, and per-pixel color overrides.

## Export

The right inspector keeps export formats close to the icon. SVG, coordinate JSON, binary matrices, and a string format can all be copied from the same place, so the app works as a quick bridge between drawing and implementation.

<ImageModal src={editorCode} caption="Generated SVG and JSON are available in the code inspector" />

## Process

Glaze made the iteration loop feel closer to directing a product prototype than starting a desktop app from scratch. The agent maintained its own project memory as the app evolved, which was useful for keeping UI decisions consistent across later changes: dashboard density, inspector tabs, import behavior, tag management, cursor behavior, and export preferences all stayed documented as the app grew.
